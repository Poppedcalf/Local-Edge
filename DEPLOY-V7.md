## Before publishing
1. Review whether every service description matches what Local Edge is ready to deliver. Narrow or remove anything you cannot currently fulfil.
2. Confirm that the published starting prices and care-plan terms remain correct.
3. Confirm the form is still using the prepared WhatsApp/email handoff, unless a real form endpoint has been configured and tested.
4. Upload/replace the project files while keeping the existing file and folder structure.
5. Test the homepage, What We Do page, Work page, About page, mobile navigation and enquiry form on the live URL from an actual phone.
6. Check that the social preview updates; sharing platforms may cache old images for a while.

## Important positioning note
The broader offer is intentionally described as support and individually scoped work. Do not promise a fixed number of leads, enquiries, bookings or revenue. Agree on deliverables, responsibilities, fees, commission attribution and reporting in writing for each engagement.
